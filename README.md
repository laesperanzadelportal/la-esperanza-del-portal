# La Esperanza del Portal — página web

Página creada para la MIPYME / asociación **Asociación de Padres de Familia y Madres Comunitarias de los Hogares de Bienestar La Esperanza del Portal**.

Incluye:
- Identidad visual verde, crema y amarillo.
- Inicio institucional.
- Quiénes somos.
- Propósito.
- Los 13 hogares nombrados en los estatutos consultados.
- Los 3 FAMI nombrados en los estatutos consultados.
- Servicios/áreas de atención.
- Galería tipo carrusel.
- Valores.
- Contacto.
- Diseño responsive.

Las referencias institucionales usadas para el contenido incluyen documentos del ICBF y los estatutos publicados en línea. Las fotografías son imágenes de referencia externas y deben reemplazarse por fotografías propias o con licencia para una publicación definitiva.

## GitHub Pages
Sube `index.html`, `style.css` y `script.js` al repositorio. Luego:
Settings > Pages > Deploy from a branch > main > /(root) > Save.

## Datos
El teléfono y correo mostrados proceden de documentación histórica consultada; conviene verificar que sigan vigentes antes de publicar.
